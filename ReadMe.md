## 🚀 Projetos em destaque

### 🔧 [TocantinsMotores](https://github.com/PedroHenriquepso/TocantinsMotores)
Sistema desktop de **gestão de estoque** para loja de peças: várias lojas, transferências entre filiais, saídas para clientes, cotações com fornecedores (exporta PDF e Excel), usuários com perfis de permissão e log de auditoria.
`C#` `Windows Forms` `SQL Server` `BCrypt`

### 📦 [StockFlow](https://github.com/PedroHenriquepso/stockflow)
Sistema web de **vendas e estoque** para pequenas empresas, com API REST, login com JWT, orçamentos, vendas com baixa automática de estoque e dashboard. *Em desenvolvimento.*
`Python` `FastAPI` `SQLAlchemy` `SQLite` `JavaScript`
